# DDEV bundle

Prerequisites:
- Docker or another container provider is installed and running.

Install DDEV:
1) Review and run your preferred option from `install-linux.sh`.

Create a project:
1) From an existing project directory, run `ddev config` and answer the prompts.
2) Start services with `ddev start`.

Notes:
- DDEV stores project settings in `.ddev/config.yaml`.
- A starter example is included under `starter/.ddev/config.yaml`; copy it into your project if helpful and adjust values.
